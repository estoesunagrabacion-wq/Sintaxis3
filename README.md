# Sintaxis de tercer año

Tutor de sintaxis para estudiantes de 3.er año: teoría y ejercicios corregidos al instante, siguiendo los tres cuadernillos. Es un único archivo HTML (`index.html`), sin dependencias; el avance se guarda en el propio dispositivo.

Las claves de los ejercicios son un borrador a revisar; los análisis discutibles están marcados como tales.

`fuente/` contiene el código con el que se arma el archivo.
